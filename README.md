# Logos Grupo OIKOS

Host público y permanente de los logos de empresa y proyectos del Grupo Empresarial OIKOS,
para usarlos en correos HTML (`<img src="...">`) y otros comunicados.

- **Catálogo navegable:** https://oikostecnologia.github.io/logos/
- **URL de cada logo:** `https://oikostecnologia.github.io/logos/<archivo>`

Los archivos se sirven vía GitHub Pages: URLs directas a la imagen, con el `Content-Type`
correcto, que sí se renderizan en los clientes de correo (a diferencia de los enlaces de
Google Drive o de postimg.cc).
